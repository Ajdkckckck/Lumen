# ЛЮМИ — Telegram-бот заботы и поддержки 💖

Персональный Telegram-бот для заботы, поддержки, хранения личной информации, управления целями, привычками и персонализации.

## Функции

- 💌 Комплименты
- 🫶 Поддержка (категории: грустно, хочу улыбнуться)
- 📓 Дневник (защищён паролем)
- 📬 Письма от админа (защищены паролем)
- 📖 Воспоминания (защищены паролем)
- 😊 Трекер настроения
- 🎯 Цели
- 🏆 Достижения
- 💪 Привычки с напоминаниями
- 📦 Капсула времени (защищена паролем)
- 🎁 Сюрпризы (защищены паролем)
- 🔐 Личные секреты (защищены паролем)
- 🧠 Режим заботы
- 📊 Статистика
- 📝 Заметки
- ☀️ Автоматические сообщения (доброе утро / спокойной ночи)

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env`:
```bash
cp .env.example .env
```

5. Заполните `.env`:
```
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
```

## Запуск

```bash
python run.py
```

## Часовой пояс

Бот работает в часовом поясе **Asia/Yekaterinburg** (Уфа, UTC+5).

## Пароли по умолчанию

Все защищённые разделы имеют пароль по умолчанию: `1234`. Измените их через админ-панель (`/admin` → 🔑 Сменить пароль).

## Админ-команды

- `/admin` — открыть панель администратора
- `/menu` — показать главное меню
- `/set_morning <текст>` — изменить утреннее сообщение
- `/set_night <текст>` — изменить ночное сообщение
